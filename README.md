# Tokyo Ghoul RPG

RPG-мод для Minecraft 1.20.1 (Forge) по мотивам Tokyo Ghoul: классы, кагуне, боевые способности и дерево навыков.

## Как собрать мод на GitHub
1. Создай на GitHub пустой репозиторий.
2. Загрузи в него всё содержимое этой папки вместе с папкой `.github` (она может быть скрыта: на Mac нажми Cmd + Shift + точка). Проще всего через GitHub Desktop, а в браузере: Add file → Upload files, перетащи все файлы и папки.
3. Открой вкладку Actions. Сборка «Сборка мода» запустится сама, это занимает 5-10 минут. Запустить заново можно кнопкой Run workflow.
4. Когда появится зелёная галочка, открой сборку и внизу в разделе Artifacts скачай `tokyoghoulrpg-mod`. Внутри лежит файл `tokyoghoulrpg-0.5.0.jar`.

Если сборка красная, открой шаг «Собрать мод», скопируй текст ошибки и пришли мне.

## Как играть
Нужен Minecraft Java 1.20.1 с Forge 47.x. В папку `mods` положи два файла:
- `tokyoghoulrpg-0.5.0.jar` (твой мод)
- GeckoLib 4.4.9 для Forge 1.20.1 (скачай на CurseForge или Modrinth)

Для сборки на своём компьютере нужны Java 17 и Gradle 8.1.1: команда `gradle build`, готовый файл появится в `build/libs`.

## Управление
Выбери гуля или полугуля. Кагуне видно в третьем лице (F5) и у других игроков.

| Клавиша | Что делает |
|---|---|
| G | включить / убрать кагуне |
| V | укус: житель, игрок или разбойник в 3 блоках перед тобой |
| H | рывок на 2-3 блока вперёд |
| L (держать) | блок |
| K | барраж: 32 удара за 4,5 с по области 3 × 2 блока (нужно кагуне) |
| J | ярость, когда шкала полная |
| ЛКМ | обычная атака кагуне (нужно кагуне) |
| ПКМ дважды быстро | сильная атака, два удара (нужно кагуне) |
| Shift + ПКМ | подтянуть себя к блоку или существу до 10 блоков (нужно кагуне) |
| Shift + ЛКМ | притянуть существо до 10 блоков к себе (нужно кагуне) |
| B | дерево навыков |
| N | задания (пока заглушка) |

Команды (нужны права оператора):
- `/tgrpg rage 100` заполняет шкалу ярости
- `/tgrpg ragelevel 0..5` задаёт уровень ярости: 0 это минимум из спеки, 5 максимум
- `/tgrpg points 10` задаёт очки навыков
- `/tgrpg reset` сбрасывает класс

## Дерево навыков (B)
Пока в нём одна ветка: Ярость I-V. Каждое улучшение открывается по порядку и усиливает сразу длительность, урон, скорость и защиту ярости: от минимума до максимума из спеки на пятом уровне. Очки навыков даются за убийства. Для человека и агента CCG дерево появится позже.

## Твои файлы в игре
Каждый файл из твоего архива используется в моде:

| Файл | Где используется |
|---|---|
| `geo/kaneki_crimson_kagune.geo.json` | кагуне за спиной |
| `geo/kaneki_crimson_kagune_veins.geo.json` | вены ярости: 63 куба `rage_veins_*` из `01_rage.bbmodel`, те же кости, что у кагуне |
| `textures/kagune/kagune_crimson.png` | кагуне |
| `textures/kagune/kagune_rage_veins_animated.png` (+ `.mcmeta`) | вены: пульсирующая анимированная текстура |
| `textures/kagune/kagune_rage_veins_emissive.png` | вены: вспышка в первые 8 тиков ярости |
| `animation kagune_appear` / `kagune_retract` | G: включить / убрать кагуне |
| `animation kagune_attack_right_thrust` / `kagune_attack_left_sweep` | ЛКМ, удары чередуются |
| `animation kagune_attack_double` | ПКМ дважды: сильная атака |
| `animation kagune_barrage` | K: барраж |
| `animation kagune_dash` | H: рывок, если кагуне включено |
| `animation kagune_grapple` / `kagune_grab_pull` | Shift + ПКМ / Shift + ЛКМ |
| `animation kagune_rage` | пока действует ярость, вместе со светящимися венами |
| `ability_sync.json` | тайминги ударов, баррага и захватов |

Из `kagune_appear` я собрал `kagune_idle`: это поза стойки, из неё начинаются все остальные анимации. Вены ярости светятся как глаза паука, а пока ярости нет, их текстура прозрачная. Файлы Blockbench (`.bbmodel`) лежат в папке `blockbench` как исходники: в игру попадают модели и анимации, которые из них выгружены.

## Папки
- `src/main/java`: код мода
- `src/main/resources/assets/tokyoghoulrpg`: твои модели, анимации и текстуры кагуне (`geo`, `animations`, `textures`) и русские тексты (`lang`)
- `src/main/resources/data/tokyoghoulrpg/ability_sync.json`: тайминги ударов и захватов из твоих анимаций
- `blockbench`: исходные файлы Blockbench (`.bbmodel`) и старая версия текстуры вен. В игру они не попадают, лежат как исходники.
- `.github/workflows/build.yml`: автоматическая сборка

## Что ещё не сделано
- Вариант кагуне «Авторский» использует модель Канеки: отдельной модели нет.
- Анимации захватов рисуют щупальце в фиксированную точку перед игроком, к реальной цели оно пока не тянется.
- Задания (N), NPC, предметы, оружие, маски и одежда.
- Дерево навыков для человека и агента CCG, остальные ветки гуля.

## Числа и допущения
Числа, которых не было в спеке, собраны в `src/main/java/com/tokyoghoulrpg/combat/Balance.java` и помечены `[ВРЕМЕННО]`, значения из спеки помечены `[СПЕКА]`. Допущения:
- Способности пока только у гуля и полугуля. Кагуне (G) нужно для баррага, атак и захватов, а укус, рывок, блок и ярость работают без него.
- Пока кагуне включено, ЛКМ отдана под атаки и не ломает блоки: выключи кагуне (G), чтобы копать.
- Блок гасит урон от существ (мобы, игроки, стрелы), но не падение и не огонь. Пока держишь блок, другие способности недоступны.
- Сильный удар и любой удар в ярости ломают блок, и урон проходит. Барраж атакующего без ярости блок гасит полностью.
- Попавший под барраж не двигается до конца серии. Если оглушить атакующего, серия прерывается.
- Захваченная цель обездвижена от момента захвата до отпускания.
- При включении ярости шкала обнуляется и показывает оставшееся время.
- Голод у гулей тратится в 0,6 раза от обычного.
- Анимация `kagune_idle` (поза стойки) собрана из последнего кадра `kagune_appear`: все остальные анимации начинаются именно с неё.
